# Smart Traffic Light System

Ambulance-priority traffic light dispatch system. Three components:

- **smart traffic lught system/** — FastAPI backend tracking driver GPS and traffic light state
- **mobile-app/** — driver's phone web app
- **hq-dashboard/** — dispatcher's control panel
- **esp32-firmware/** — ESP32 client that polls the server and drives the physical light

See each subfolder's own README for details.
